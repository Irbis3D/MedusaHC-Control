CALIBRATION FUNCTIONS

Calibration

Each button independently calls the corresponding calibration function configured in Klipper.

CALIBRATE_AND_SAVE_OFFSETS

XYZ tool calibration

Runs the configured SexBall, Nudge or compatible klipper-toolchanger XYZ offset calibration.

TOOL_Z_CALIBRATION

Tool Z calibration

Calibrates only tool Z offsets through the configured Klipper tap probe.

Z_TILT_ADJUST

Z Tilt

Levels the independent Z drives using the configured Klipper Z tilt probe points.

BED_CALIBRATION

Bed calibration

Runs the configured MedusaHC bed calibration entry point for Eddy or BLTouch.
